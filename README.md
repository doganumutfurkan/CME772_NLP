# CME772_NLP

A repository prepared to collect visual materials, mini demos, and study notes for the CME772 Natural Language Processing course in one place. Each study is organized in its own topic-focused folder, allowing future projects to be developed independently without breaking existing work.

## Content Map

| Directory         | Title                                      | Description                                                                                                        |
| ----------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `word_alignment/` | Edit Distance and Alignment Visualizations | A module demonstrating weighted edit distance computation, backtrace visualization, and loop-based code templates. |
| `shannon_game_perplexity_backoff_interpolation/` | Shannon Game, Perplexity, and Smoothing | An educational mini-project that illustrates core N-gram language modeling concepts—such as Shannon sampling, perplexity, and smoothing—through concise, well-commented Python modules designed for learning and experimentation. |
| *(new additions)* |                                            | As new topics are added, each will appear in its own directory with a README and study notes.                      |

## General Usage

1. **Install dependencies**

   * Python 3.9+
   * Common libraries: `matplotlib`, `numpy`
   * Module-specific libraries are listed in each folder's README file.

2. **Navigate to the related module directory** and review the README/study notes.

   * For example, check the `word_alignment/` directory for the edit distance demo.
   * Execution commands and sample outputs are explained step by step in each module's README.

3. **Figures and explanations** are usually displayed in Matplotlib windows instead of being printed to the console. Scripts wait until the figures are closed.
